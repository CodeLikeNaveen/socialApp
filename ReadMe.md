# **=>Frontend:**
## starting commands:
    - npm create vite@latest
    - cd project
    - npm install tailwindcss @tailwindcss/vite
    - npm install lucide-react
    - npm install react-router-dom
    - npm install @clerk/react
    - npm install moment
    - npm install react-hot-toast
